# Zeno AI Tutor

Your smart tutor — any subject, any language.

## Deploy to Vercel

1. Upload this folder to GitHub
2. Go to vercel.com → New Project → Import your GitHub repo
3. Deploy — done!

## Features
- Auto language detection
- Voice input & text-to-speech
- 6 subjects: Math, Science, History, Languages, Islamic Studies, Coding
- 3 modes: Explain, Quiz me, Simplify
- Dark academic purple theme
